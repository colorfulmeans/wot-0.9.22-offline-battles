# 导航寻路、网格与路线编辑说明

适用版本：1.0.0；支持客户端：中国区高清版《坦克世界》0.9.22.0.1 #1513。

## 一、路线点和导航网格的区别

编号路线点是编辑者指定的大致行驶走廊；底层网格是寻路实际使用的地面节点及连接。BOT按路线点顺序决定去哪里，再用网格和局部检查寻找点间通路。

加密底层黄色小点，不等于增加编号路线点。加密可修复粗格中心落墙、狭窄街道缺少连接等分辨率问题，不能把真实建筑、山体或深水变为道路。

## 二、寻路与通过判定

导航采用带代价的图搜索，结合地面高度、可用连接、车体净空、坡度、水体和地图边界。底层路径可经过局部绕行、平滑和实际运动检查。车辆、尸体、可破坏物及窄通道仍需运行时处理。

有向连接决定两个方向是否都能通过；桥上、桥下及高差道路不能仅凭二维截图线段相交就视为连通。明确不可达候选可在路线获取时排除，不能把正在等待异步检查直接当成已确认障碍。

桥梁位置的高度一律以桥面高度为准，因此编辑路线时需要避免横穿桥下。

水体采用当前1.2米通过政策，并保留岸沿支撑和跌落保护。浅水可作为代价较高的备选，不能因此把深水全部开放。

## 三、局部网格加密

基础网格与局部细化层共同工作。保留大范围基础分辨率，只对实际道路中的窄口、墙角、桥头等位置添加有界细化区。局部层按自身高度与危险标记检查，不能继续只读粗层。

| 地图 | 当前细化方式 |
| --- | --- |
| 锡莫尔斯多夫及冬季版 | 保留基础图，增加窄通道局部层 |
| 飓风小镇 | 处理桥面、入口和已核对浅水岸边连接 |
| 斯大林格勒 | 14个有界的2米细化区，保留人工路线点 |
| 齐格菲防线 | 4个2米城区区域，另有16×18米的1米墙角小区 |

相同面积从4米网格改成2米，采样数量大致增为4倍；从4米改成1米大致16倍，实际还取决于边界与不可通行节点。因此优先局部细化并调整采样位置，不对整图盲目加密。

加密同时保留碰撞、净空、坡度、水体、对角连接检查。当前编辑器显示和检查已有网格，不能把“导入地图”当成生成新导航网格；导入地图用于编辑背景图。

## 四、方案、地图、队伍与视图

进入“Bot战术 → 进攻路线／火炮炮位”。Default只读，新建自定义方案后编辑，保存草稿或下一局应用。

“总路线”显示各车型实际生效路线，选中后仍定位到某一条具体路线；“全部车型”为黑色共同编辑入口。共同编辑只覆盖当前地图、队伍、同一路线族的普通车型，不包括独立火炮出击路线。单车型可再单独修改；之后再次编辑全部车型，以最新共同编辑的点位、点序及回防挂接为准。

启用且允许路线对称时才同时更新另一队。不对称地图禁用对称；普通队伍切换只显示本队回防线。

## 五、主路线编辑操作

- 新建普通路线自动带固定首尾并选中首点。中间可插点，不能把点追加到固定终点之后。
- 左键点已有节点为选中并可拖动，点空白处不自动新增主路线点。
- Shift＋点击在选中点之后插入；终点约束仍有效。只有首尾时在中间插入。
- 总路线视图选中节点后先定位路线；重叠时可从列表选择。
- 选中或双击合法大点可进入等待位编辑；等待位模式点空白处新增等待位，默认60秒。
- 选中炮位后点地图可直接移动炮位，与普通路线拖点不同。
- 支持复制、删除、撤销、重做及恢复操作。每条普通路线最多16点，相邻点至少间隔1米。

普通路线起点是己方出生点。双方出生点均在基地圈内且支持对称时，以双方出生点为固定首尾；不对称且出生与基地不重合的地图，以己方出生点至敌方基地圈为目标。火炮出击始终固定己方基地至敌方基地。

普通点抵达半径为6米，并处理经过圆圈、已越过节点等情况。选中点显示实际范围，最终基地以占领圈抵达为准，不要求压住一个精确点。

## 六、主要、备用、禁用与删除

主要路线以车型色实线显示，备用路线以同色虚线显示。主要优先用于前三辆的分散分配，容量不足后考虑备用；实际统计跨同一路线族各车型共享。

只能在“全部车型”范围删除路线，不能单车型删除整个路线族。内置默认路线删除后为禁用，可恢复；用户新建路线删除则清除对象和引用。旧单车型隐藏删除条目已转为可见备用，不再把备用误当禁用。

“转换为主要／备用”切换当前路线对应状态，当前状态按钮灰显。“恢复默认路线”恢复内置点位、等待位、主备用及回防线，不删除用户新建路线。

## 七、等待位与回防线

等待位属于正向路线任务，回防、折返及无弹赶路不等待；重新进入一条新路线后按新任务正常处理。

回防线从合法中间普通节点挂接至己方基地。等待点、炮位、首尾点不能挂接；已挂回防线的节点也不能变为等待点。挂接绑定稳定节点身份，插点不能只凭序号错误接到别的点。

添加后两端固定，中间可增删拖动，虚线标“回防”；进入回防编辑状态后只编辑这条连接。删除／移动主节点、共同覆盖、复制、导入、撤销、重做均需维护连接。

普通默认回防线配置于密特朗、喀秋莎和失落小镇。其他地图未配回防线不自动算错误，回程采用原路线至起点再往基地。具体运行见第3份说明。

## 八、火炮编辑

炮位与普通回防线分开。炮位是自动部署目标，可编辑位置和朝向；不编辑固定基地—炮位或炮位间连接。

火炮残局出击为独立红色虚线路线，在左侧火炮驻炮点之后可选。它不参加普通车型主备用共同编辑，首尾为双方基地。说明为“仅剩火炮时，最多选3门有弹火炮沿该路线出击”；无弹火炮另有资格例外及借线规则。

## 九、检查本图与危险区显示

“检查本图”按实际生效配置展开，覆盖双方队伍、各车型、主要／备用、等待位、炮位、火炮出击和回防线，区分：配置且正确、配置但是错误、未配置；禁用条目另列。结果可定位到具体路线、节点和连接，编辑后旧结果失效。

“显示导航网格”展示实际基础及细化网格；“显示危险区网格”显示危险标记，可悬停查看。红色不一律等于绝对禁行：深水、岸沿保护和已审核渡口的含义不同；缺地面高度、无连接也应分别识别。

检查通过表示“导航数据检查通过”，不是在任意尸体、拥堵和车体尺寸下必定畅通。报告问题时提供地图、队伍、车型、路线名和具体点号，最好附坐标及截图。
