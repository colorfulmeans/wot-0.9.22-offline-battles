# 车辆支撑、跌落与碰撞伤害说明

适用版本：1.0.0；支持客户端：中国区高清版《坦克世界》0.9.22.0.1 #1513。

## 一、五点支撑检测

系统检查车体中心、前、后、左、右五个位置的真实地面支撑。采样位置随车体朝向、俯仰和侧倾变化，不是只检查地图上的固定十字。

五点是支撑模式的切换依据，不表示整套悬挂只有五个物理接触点。详细求解还包含悬挂、车体接触、速度及落地处理。

## 二、何时切换支撑模式

| 条件 | 处理 |
| --- | --- |
| 正常地面完整支撑 | 使用简化支撑 |
| 至少一个采样点失去有效支撑 | 启用详细支撑 |
| 仍在空中或仍有失效点 | 保持详细支撑 |
| 五点恢复有效、已经落地且落地／接触结算完成 | 交回简化支撑 |

交接保留已经接受的车体高度、姿态和速度，清除旧坡面姿态目标，之后继续核对真实支撑。不能一发现五点有效就提前丢弃本次落地伤害，也不能切回后沿用旧姿态把车体扭回去。

地面判断结合高度层和连续地形。车体上方的桥面、屋顶不是车底的支撑地面；正常连续上坡也不能仅因高于某个采样界限就当作悬空。

这种切换减少完整支撑区域持续详细求解的开销，复杂支撑和跌落仍保留详细处理。

## 三、跌落生命值损伤

跌落伤害依据实际落地冲击速度，不按“从地图上看落差几米”直接固定扣血。当前默认安全冲击速度为10米／秒，超过部分按每增加1米／秒损失最大生命值的3%计算，并取整数。

例如最大生命值1000、有效冲击速度15米／秒，对应基础跌落损伤150。最终结算还受实际接触、其他同时发生的伤害及车辆剩余生命值影响。支撑采样失效本身不是伤害事件，必须有实际落地或撞击证据。

不同接触面按实际运动与接触方向处理，不能把坡地持续行驶的普通高度变化反复当作跌落。被推下桥或承载物后仍保留真实被动物理运动。

## 四、坠落造成的模块与成员损伤

除车辆生命值，落地冲击还可能损伤实际接触所涉及的外部部件、内部模块和成员位置。

冲击从真实接触采样沿撞击方向进入车体，结合外部碰撞材料和当前采用的内部布局选择对象；没有命中的模块不随机分摊伤害。多个采样触及同一模块时合并，重复消息不重复结算同次撞击。

当前离线模块损伤基础系数为超过安全速度部分每1米／秒25模块生命值，再乘以接触位置权重。成员受伤采用相应冲击阈值判断。此处系数属于本项目离线规则，不是从原版服务器恢复的公式。

安全落地不产生额外模块损伤；内部几何缺失时不伪造一个位置补命中。燃油箱被撞毁可引发起火，弹药架被撞毁可导致爆炸，成员全部失去战斗能力也有对应终局处理。模块布局覆盖问题见第9份清单。

## 五、起火后的生命值和模块损伤

当前基准燃烧每秒损失最大生命值的5%，默认持续10秒，灭火或终局可提前结束。按实际燃烧时间累计整秒结算，更新变慢时不会只算一次而漏掉已经经过的燃烧周期。

| 损伤对象 | 燃烧处理 |
| --- | --- |
| 发动机、燃油箱、弹药架、电台、炮塔旋转机构 | 对具备有效生命值池的模块，每个燃烧秒损失10模块生命值 |
| 履带、火炮等外部模块 | 不加入这一内部模块持续燃烧列表 |
| 成员 | 不由这套燃烧模块损伤直接击伤 |

模块受损可进一步降低到损毁状态，弹药架耗尽可爆炸。车辆死亡后不继续添加后续燃烧损伤。灭火后燃油箱恢复到该配置允许的可恢复生命值，不等于所有模块全部修好；相应改善按修复通知显示。

模块最大生命值和可恢复值来自实际车辆配置及生效因素，不能用别的车辆或研发配置替代。具体起火概率、配件、成员和给养仍按实际配置处理，不能将“10秒基准燃烧”误认为灭火器不会生效。

## 六、压车、残骸与环境归属

落到另一辆车顶时处理首次冲击和后续持续压迫，避免同次接触重复扣血。上方车辆死亡后的持续压迫作为残骸环境伤害，不继续当成原驾驶者持续输出。活车停在尸体上方，也不会仅凭这种上下关系持续受到反向压迫伤害。

撞击、坠落、燃烧和残骸压迫各自保留原因。弹药架因燃烧爆炸与因坠落损毁有相应显示；不能把全部环境伤害伪装成炮击。

玩家与BOT在相应权威路径中采用一致的损伤规则；模型、HUD和模块状态随最终结算同步。
