# 存档、成员与数据维护说明

适用版本：1.0.0；支持客户端：中国区高清版《坦克世界》0.9.22.0.1 #1513。

## 一、存档保存什么

每个存档独立保存车库、成员、账号状态和战斗记录。新建可选全解锁或新账号／生涯模式；启动游戏使用当前选中存档。

房间连接、车辆属性方案、BOT阵容和BOT战术方案另有独立管理，不因切换存档自动变成同一份。备份存档不能理解成备份所有客户端改装和全部路线。

默认全解锁存档提供全技能成员及合法紫色配件、对应指令和指令自动补给初始配置；玩家保存自己的修改后不反复重置。生涯存档按新账号初始规则使用，不套用全解锁车库。

## 二、存档页操作

- 新建存档：选择名称和模式，创建独立存档。
- 重命名：修改显示名称，不把别的存档内容合并过来。
- 删除存档：删除所选存档，执行前查看确认范围。
- 打开存档文件夹：查看当前存档实际文件。
- 备份存档：导出ZIP备份。
- 恢复存档：选择已有备份ZIP，因此会打开文件选择窗口；它不是一键回到本局之前。
- 初始化存档：将当前存档恢复为刚建档的初始模式，执行前弹窗确认。

修改、初始化、备份恢复等操作前关闭游戏，避免运行中状态覆盖磁盘修改。恢复覆盖范围以确认窗口为准。

## 三、成员编辑器

入口：“存档 → 自定义存档 → 成员”。

1. 选国家和坦克类型，再选真实可用车辆。
2. 选该车实际专业席位；兼任职责会显示在专业后，同名重复席位分别列出。
3. 选男性／女性、50%／75%／100%训练水平、技能和特长数量。
4. 检查可用床位，点击“添加到兵营”。
5. 下次启动该存档时投放成员，客户端系统消息提示结果。

技能上限按实际席位全部兼职职责计算，共享技能只计一次。100%训练后具体技能在客户端选择；不是启动器指定每项技能的顺序。低于100%时不能选普通技能权益。

女性成员自带零经验兄弟连，该技能计入所选技能总数。成员姓名、头像等身份数据按女性配置生成。成员技能经验和权益归成员所有，换车、换座或重启不会重新赠送一套。

招募请求绑定当前存档并持久保存。发送后退出或下次领取中断可重试，不应重复投放。暂时床位不足则保留请求；存档备份与恢复也处理待领取成员请求及相关权益。

## 四、兵营床位

“添加16个兵营床位”每次固定增加16，只扩充、不缩减。招募前可用量计算考虑现有兵营成员和待投放请求，避免连续添加超额。

启动器提示不足时先扩充再添加。现有已排队请求在运行端仍受容量保护，不因请求存在就强行超过床位。

国家使用完整名称，与车库坦克栏目一致。顺序遵循客户端车库：中国、苏联、美国、德国、捷克、法国、英国、日本、波兰、瑞典；只列实际可用国家。

## 五、车库与涂装

自定义存档中的车库获取只提供合法可用车辆。涂装页可添加兼容样式、补齐缺失样式及编辑库存；按车辆兼容性处理，隐藏样式不等于所有车通用。

租用样式副本保留原使用次数，不因保存或重启无限补满。全解锁存档的初次样式库存初始化完成后，正常使用或出售不会每次重新补回。

## 六、四种维护模式

| 功能 | 清理与恢复范围 |
| --- | --- |
| 修复模组安装 | 重新安装当前启动器随包模组，保留可用存档和方案；不联网获取最新版 |
| 重置全部离线客户端设置 | 重置离线玩家、隐藏客户端及旧离线设置中的画面、声音、输入等，不清空存档，不重置正常客户端原版设置 |
| 清空全部离线存档 | 删除所有离线存档、遗留副本和待投放请求，重建默认全解锁存档；保留战术、车辆方案及客户端设置等其他数据 |
| 删除全部数据并恢复出厂 | 清除项目管理的存档、方案、路线、阵容、设置、历史、缓存、录像、日志、报告及中断残留，恢复所管理的车辆覆盖并重新安装当前包模组、建立默认数据 |

四项都弹窗确认。操作前关闭游戏、隐藏客户端、房间及其他旧启动器；后台写入或报告收集仍进行时可能拒绝维护。恢复出厂成功后启动器关闭，重新打开使用初始状态。

“修复模组安装”恢复的是点击该按钮的启动器自带版本。例如先用旧包再用新包，安装内容随实际使用包改变，不是每个包各维护一套互不影响的游戏模组。

这些离线数据由不同版本启动器共享，清空会影响其他版本；手动复制到其他位置的文件不会删除。

## 七、常见区别

初始化当前存档只针对所选存档；清空全部离线存档影响所有存档；恢复出厂还清路线、阵容、设置、录像和报告。不要将三个操作当成同一件事。

Default战术方案只读与默认全解锁存档是不同概念。切换存档不等于切换战术方案；恢复默认路线也不等于初始化成员和账号。

核对依据：save_slots.py、save_customizations.py、save_ledger.py、crew_store.py、crew_ui.py、nation_choices.py、core.py和wot_launcher.py的维护处理。
