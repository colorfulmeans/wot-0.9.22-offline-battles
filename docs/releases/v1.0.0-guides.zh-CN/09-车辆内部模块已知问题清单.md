# 车辆内部模块已知问题清单

适用版本：1.0.0；支持客户端：中国区高清版《坦克世界》0.9.22.0.1 #1513。

核对日期：2026年10月27日。

## 一、这份清单记录什么

本清单重新扫描当前支持客户端680条车辆定义，对照现有内部模块／成员布局。它记录定位几何的覆盖情况，不将每个缺项直接宣布为实战BUG，也不把布局覆盖当作能否装载车辆的唯一条件。

内部模块包括发动机、燃油箱、弹药架、电台、观察装置、炮塔旋转机构等；主炮和左右履带还有原生外部命中路径。内部布局缺失不等于这些原生外部模块全部失效，也不等于车辆没有模块生命值、不能修理。

| 类别 | 数量 | 含义 |

650＋22＋8＝680；650中有474条没有本次源清单记录的模块／成员槽位缺项。没有记录缺项不等于已经对每种炮塔、每种模型完成实战逐模块验收。

176条部分缺项涉及观察装置、炮塔旋转机构及2条车辆定义的部分成员槽位。对没有炮塔旋转机构的固定战斗室车辆，缺少该几何不应直接视为错误；需结合实际部件存在性判断。

所有658条已有编译档案的车辆，记录的成员职责与本客户端定义匹配。本次列表核对的是源数据与编译记录，不声称发现或修复新的模型碰撞问题。

## 三、影响与当前处理

- 没有内部布局：不按车型随机创造一个发动机、弹药架或成员命中点。依赖内部定位几何的受击结果存在覆盖缺口。
- 重建布局：仍有相应布局可用，但几何来源与精确模型不同，需要保留来源区别。
- 部分缺项：只列缺失对象，不能把整辆车其余已覆盖部位都算成缺失。
- 资源不可用：与模块布局分开标明，当前通常已经被正常车辆列表排除。
- 非普通对局或BOT专用排除：按第6份筛选规则处理，不因出现在本清单中自动重新加入随机池。

“可手动获取、BOT排除”指当前明确保留玩家手动用途的退役车；“非普通对局条目”指活动、教学克隆或占位等筛选对象。

同名车辆可能对应不同完整标识，报告时请保留表中的国家前缀和车辆标识。成员槽位缺口、内部几何缺口和模块生命值不一致是不同问题，需描述具体受击位置、炮弹／坠落／起火来源以及实际损伤。

仅凭“打了某处没有坏弹药架”不能确定布局错误，还需考虑真实命中部件、穿透路径、剩余模块生命值和伤害结算。建议从诊断入口复现并提交完整报告；不根据单次未损坏就更改模型。
