# 对局组队、BOT补位与车辆筛选说明

适用版本：1.0.0；支持客户端：中国区高清版《坦克世界》0.9.22.0.1 #1513。

## 一、房间人数和BOT补位

离线房间按双方队伍人数补齐BOT，每队上限15辆。人类玩家占对应队伍名额；启动器固定BOT槽位优先保留，其余位置才自动补足。局域网房间中的人类加入和队伍选择会影响剩余BOT位置。

自动阵容以等级、车型和当前有效车辆池构造，不是照抄网络排队系统。双方可使用相同的等级／车型模板，但不要求每一辆是完全相同型号；固定阵容和自定义人数会影响最终构成。

## 二、等级范围

| 设置 | 以玩家参考等级为T的自动BOT范围 |
| --- | --- |
| 同级 | T |
| 低1级到同级 | T−1、T |
| 同级到高1级 | T、T＋1 |
| 上下1级 | T−1、T、T＋1 |
| 低2级到同级 | T−2、T−1、T |
| 同级到高2级 | T、T＋1、T＋2 |
| 随机 | 在合法连续窗口中选择，通常覆盖1—3个等级 |

等级限制在1—10，且需有实际候选。随机档使用当前人类等级和有效目录确定一个窗口，不是每个BOT各自随意在五级范围抽取。普通随机窗口宽度选择基准为同级28%、两级44%、三级28%，实际会因人类等级跨度和候选可用性调整。

15人模板的三级房倾向低／中／高7／5／3，两级房低／高10／5，同级房全同级。小队伍按比例缩放，人类预留、固定阵容及车辆池不足可改变这些数量，不是硬性保证每局完全一致。

## 三、随机车型与手动车型

双方独立设置。随机模式下五个车型框显示勾选但不可编辑，同时记住手动选择；切回手动可继续使用之前的选择。

手动模式：勾选车型至少保证1辆BOT，未勾选车型禁止参与自动补充。玩家自己的车型不能抵扣BOT保证；启动器固定BOT可以满足其车型保证，且不会因客户端勾选被替换。

勾选种类不能超过实际可分配BOT数量。人数缩小时按最后勾选先取消，保留较早选择，系统消息说明取消项目；人数增加不自动勾回。手动五项全空自动回到随机。

## 四、火炮数量

| 队伍总人数 | 随机模式自动火炮范围 |
| --- | --- |
| 1—6 | 0 |
| 7—9 | 0—1 |
| 10—12 | 0—2 |
| 13—15 | 0—3 |

自动余量会考虑人类及固定火炮。手动勾选火炮时，即使小队伍也保证至少1门BOT火炮；后续仍受合法阵容和数量规则约束。固定阵容可用于专门全火炮测试，不等于随机补位可以突破限制填满15门。

例如只勾SPG而需要自动补15辆，不能满足合法火炮上限时拒绝开战。不会为了补满改成未勾选的车型。

## 五、无合法车型时的处理

若选1级车，匹配低2级到同级，实际窗口只有1级；只勾HT／TD／SPG而该等级不存在这些车型，会显示缺少合法候选并阻止开战。固定等级模式不会悄悄提高等级来满足勾选。

随机等级模式可在允许条件中寻找能覆盖保证车型的合法窗口；仍无解时拒绝。车型保证、等级范围、可用车辆和火炮上限需同时满足。

## 六、车辆筛选层次

1. 读取支持客户端真实车辆目录，要求合法等级、名称、车型与资源。
2. 排除缺模型、碰撞模型或被旧占位模型替代的车辆。
3. 排除活动、特殊玩法、网吧及观察者等非普通对局条目。
4. 按secret标记配合后缀排除教学克隆、BOT／训练占位实体及炮击发射实体；secret本身不一律禁止车辆。
5. BOT再排除当前代码明确列出的5辆已退役车辆；可用资源的手动玩家获取不必采用这一BOT专用排除。
6. 在剩余池中应用房间等级、车型及固定阵容要求。

unrecoverable表示部分出售恢复规则，不应直接解释为不能开战；合法隐藏奖励车也不能仅因未在商店销售就一律排除。

## 七、玩家获取车辆与成员选择

车库获取车辆和成员训练车辆共用标准车辆及模型有效性判断，避免出现FV4202 105等无效旧条目。成员选择还要求实际席位数据匹配。

成员目录不应直接照搬BOT退役排除表，否则会使仍可供玩家使用的车辆无法招募对应成员。内部模块布局缺失又是另一类问题，不自动等同于车辆不能显示或不能入场，见第9份清单。
