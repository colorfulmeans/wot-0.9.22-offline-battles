# BOT行动、进攻与回防逻辑说明

适用版本：1.0.0；支持客户端：中国区高清版《坦克世界》0.9.22.0.1 #1513。

## 一、任务优先级与例外

正常有弹车辆的任务优先级为：自动回防基地 → 交战 → 脱困 → 战线调度 → 玩家指令 → 普通路线移动。

交战指遇敌后的瞄准、接近、停车射击等现有交战任务，不是“沿路线前往敌方基地”的另一种称呼。自动回防赶路时车身以回防为主，炮塔可顺便攻击。受阻脱困是完成当前任务的手段，不会把回防车辆强制改回普通路线移动。

彻底无弹是独立状态：不接受外部回防、调度和玩家任务，以赶往敌方基地占领为主；它自己的脱困与换线仍然有效。

## 二、普通车辆前进与路线分配

开局按同队同一路线族统计占用，优先空的主要路线，再用未满3辆且较空的主要路线；主要路线容量不足后使用备用路线。同等候选随机选择。不同车型的同名路线共享占用，避免各车型各塞3辆。已有路线都占用后仍尽量使用合法既定路线。

正常前进从出生位置接向路线第二点；第一点主要用于反向返回与换线。普通点采用6米范围抵达及经过判定，最终目标以敌方基地圈为准。点间仍有寻路、避障和真实碰撞，不是沿两点直线强制穿过所有物体。

交战结束后在原路线中选可达、实际行驶成本较低的接入点继续，不任意切到别的路线中段。正向行驶可执行等待位；折返、回防和无弹赶路跳过等待。

## 三、受阻、跳点和折返换线

以路线A、B、C、D表示原有点序：从B接近C受阻，先局部绕行、前后移动、转向或推挤；没有实际进展达到当前约20秒的宏观点尝试时间后，尝试D。D仍失败则折返B，再按A等原路线点依次退回起点。

返回途中仍处于脱困循环；不能因抵达B就提前结束。抵达旧路线起点后衔接新路线起点，直到新路线开始执行才清掉换线状态。失败一轮后继续重试，不设累计次数用完就永久停止的断点。

交战可暂停脱困计时并保留进度。交战中移动过，恢复时从实际位置重新寻找连接。真实撞墙、深水、边界及车体净空检查仍有效，跳点不赋予穿墙能力。

## 四、战线调度

每180秒评估一次，用于缓解长期双方无法接战的局面。车辆先沿旧路线反向返回起点，再进入调度目标路线，不从半路直接横切过去。任务到期时未完成换线则接回旧路线已通过位置，完成换线后继续新路线。

正在脱困、已有转移任务、实际占领或无弹占领的车辆不被重复派援。统计区分在途预留与已到达车辆；无弹车仍计入道路实际占用。

## 五、自动回防

基地出现敌方占领者时选择可执行回防的有弹车辆。默认最多3辆，并结合占领者数量和现有防守力量调整；有多辆可用时保留前线力量，只剩一辆可用时允许它回防。机动、回程距离和能否实际参与守家都会影响选择，不能简单理解为全队同时回防。

回程沿原路线倒序走。若配置回防连接，且当前回程能顺路到达挂接点，则沿该连接进入己方基地；已经反向越过挂接点时不再掉头追它，而是回起点再走基地。没有回防线时回原路线起点，再前往基地；起点在基地圈内则进圈即抵达。

回程受阻仍可局部脱困、跳过受阻返回点。连续返回失败后有直接前往基地的兜底，但仍检查真实碰撞和不可通行条件。

自动回防在连续30秒没有敌方占领者后解除；圈内敌人即使占领点数为0，也会打断安全计时。解除后清理本次回防兜底状态，普通车接回原路线。

基地内优先攻击有合法射击机会、占领点数最多的敌人；同分沿用原目标评分。所有圈内敌人都无法有效攻击时，再考虑圈外敌人。此特例结束后恢复正常目标规则。

## 六、玩家命令

命令只交给当前有执行资格的BOT，不保证全队响应。常规响应优先附近约300米内的车辆，响应数量上限为3；可选范围和远处补选仍受具体命令与任务状态限制。

| 命令 | 行动 |
| --- | --- |
| 进攻 | 沿当前路线前进 |
| 后退 | 前往固定的上一节点；到达后结束后退并继续正常行动 |
| 返回基地 | 沿原路线反向守家，受自动任务优先级约束 |
| 注意地图区域 | 前往指定区域，结束后接回原路线 |
| 请求支援／跟随 | 跟随玩家附近位置，位置随玩家变化；玩家死亡、离开或任务结束后接回原路线 |
| 停止 | 临时原地停止，结束后恢复路线行动 |

一般移动命令有效期120秒，短时战术命令通常15秒；返回基地采用单独时限：从下达起90秒，首次抵达基地后一次性转为连续安全30秒，不回切到90秒。交战不暂停这套玩家守家计时。

每位玩家的有效命令共用10秒冷却。至少一辆BOT实际接受才开始冷却，实际接受者回复“遵命”。冷却内有资格的BOT只对首次拒绝回复“拒绝接受”，后续不刷屏；命令本身作废，不排队。没有执行者时不消耗冷却，也不回复。

新的合法玩家命令覆盖相应BOT旧命令。交战、自动回防等更高优先级任务可作废玩家命令，结束后不复活已经作废的旧命令。

## 七、占领敌方基地

普通路线末段目标是敌方基地圈，进圈即可转为占领，不追逐圈内一个精确末点。没有额外“只选3辆占领车”或外围占领警戒任务。超过3辆可以进圈；原生占领速度贡献上限与允许进入的车辆数量是两回事。

占领保护约束战术目标，避免追敌、装填调整和调度无故拉车出圈。被推离后尝试重新进入；保护不阻止碰撞、被推动或其他真实物理运动。

## 八、火炮部署与补位

火炮分为部署、残局出击、无弹出击三类状态。部署又区分有炮位和自动部署；残局出击保留回防、返回基地、换线等子任务。

开局最多分配3个炮位名额，每炮位1门，出发即预留；没有炮位名额的火炮自动寻路、自动部署并射击，不占普通车辆路线名额。炮位原车阵亡后，从自由火炮中补位；若进入炮位失败，停止该炮位本局后续补位，避免连续派车。

炮位部署、炮位间换位和返回炮位采用自动寻路，没有固定炮位连接编辑。炮位是部署目标，不是火炮必须永远停住的开火开关。

## 九、火炮残局出击与受阻换线

本队存活BOT只剩火炮时，最多3门有弹火炮进入持续出击名额；人类玩家不参与“只剩火炮BOT”的判断。优先选择自由行动火炮，再从驻炮火炮中随机选择。返回基地、途中交战及脱困均保留名额，不能因停车装填就补入第四门。其余火炮待命并可射击；名额不足时补位，残局后停止炮位补位。

出击先回己方基地，再沿红色独立火炮出击路线进攻。保留火炮自身弹道、射界、俯仰和装填，可沿途交战；不要求回原炮位才能开火。自动回防打断后保留出击身份，回防结束继续出击。

火炮受阻也执行C失败→D→折返B、A→返回基地换线。其他候选含普通车型主要和备用路线，排除禁用及明确不可达者；优先占用少的，同等随机，有其他有效选择时避开刚失败路线，无其他有效选择再重试原线。

借用普通路线时，从基地反向走其回防连接接入主线，再正向进攻；没有回防连接时从普通路线起点接入。没有自定义火炮出击路线也先回基地再选普通路线；确无有效既定路线才自动寻路。

## 十、彻底无弹状态

必须已知所有弹种真实库存全为0才触发。库存缺失、未知、装填中、弹夹暂空、只有当前弹种为0均不能触发。可由手动全0／总量0配置或战斗打空触发。

首次触发一次性清理旧交战、玩家命令、调度、回防、驻炮与旧脱困暂停状态；之后保持任务进度，不每帧重置。车辆以行驶到敌方基地占领为主，跳过等待位，被攻击也不重新停车交战。仍可顺便瞄准，原射击校验继续有效；不凭空生成炮弹，已飞出的最后一发继续结算。

无弹车不接受玩家命令，不被自动回防或战线调度选中，但仍计入道路占用。自身脱困、折返和换线有效，进入敌方基地后持续占领，被推离则重新进圈。

无弹火炮不受“只剩火炮”和最多3门出击资格限制，全部可以出击。先回基地，优先火炮出击路线；该线已有3辆后，按低占用原则选普通主要／备用路线。借线、回防连接反向接入及受阻换线规则与上述火炮出击流程一致。
