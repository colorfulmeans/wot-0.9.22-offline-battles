# v0.10.2 recovery and handoff

## Play after reinstalling Windows

1. Restore the exact Chinese HD World of Tanks 0.9.22.0.1 #1513 client separately.
2. Download and extract `wot-0.9.22-offline-battles-0.10.2-Windows-x64.zip` once, keeping the complete folder and `_internal` directory.
3. Run `wot-0.9.22-offline-battles.exe` and select the client. Use the three batch entries only for their documented test purposes.

## Restore source and history

The tagged release contains the final v0.10.2 source. Clone the public repository and check out `v0.10.2`, or extract `wot-0.9.22-offline-battles-0.10.2-Source-and-validation.zip` for a source-only copy.

For an offline history restoration:

```sh
git clone wot-0.9.22-offline-battles-0.10.2-History.bundle wot-restored
cd wot-restored
git checkout -b restored-v0.10.2 v0.10.2
```

If a bundle was prepared before the publication tag existed, restore its recorded main commit instead. The publisher creates an internal `backup/v0.10.2-source` tag before bundling so the final source always has a named restoration point.

The archive includes `src/`, `server/`, `launcher/`, `native/`, `tests/`, `tools/`, `navgraphs/`, local mesh data, `foliage/`, `destructibles/`, workflow definitions, pinned dependency inputs and documentation. Read `CLAUDE.md`, `README.md`, `INSTALL.txt` and `COMPATIBILITY_REVIEW.md` before continuing development. Follow the versioned Windows build workflow; generated executables are supplied in the runnable release asset.

## Preserved behavior and scope

- Keep real collision, obstruction checks, attacker priority and existing retry/route-switch laws.
- Detailed support enables on one invalid point and disables on all five valid points.
- Do not restore the withdrawn slope veto or experimental aim-search redesign.
- Low-health withdrawal is removed; empty-magazine withdrawal remains.
- Pressure dispatch runs at one-minute cadence; active enemy-base capturers are excluded from defense selection.
- Current low-vegetation crushing is deliberately retained despite its visual imperfection.
- Recent SU-122-44 observations show real stationary wreck contacts and active recovery/replanning; no navigation change was justified solely by its long stay.

Source tests and package inspections verify their respective contracts, not every native gameplay situation. Heavy wreck congestion can remain impassable.

## Personal data

Personal profiles, custom routes and reports are separate from the public source release. Back up `%LOCALAPPDATA%\WoTOfflineBattles` and the game client's own replay/configuration data before reinstalling. The public repository and release intentionally contain no account credentials or personal save archive.
