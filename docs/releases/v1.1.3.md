# v1.1.3 — Chinese and English text, and a Testing tab

Built from `v1.1.2`.

## Language

- The Mod's own in-game text follows the launcher's language selection (English, Chinese or Auto) from the next game start. This covers LAN connection and failure messages, the LAN server address, shell tooltips in the garage and in battle, the post-mortem causes for ammo-rack fire and fall deaths, and offline service errors. A failure without a known description points to the diagnostic logs instead of showing an internal code.
- The launcher's activity log uses the selected language and is translated again when you switch languages. The launcher log file keeps the original English lines.
- The distribution notice under the activity log and the free-distribution notice on first start show Chinese and English.
- With Chinese selected, the Bot tactics editor shows the built-in Default profile under its Chinese name.
- The download includes a Chinese guide, README.zh-CN.txt.

## Testing tab

- A new Testing tab sits between Bot tactics and Repair.
- **Collect detailed diagnostic logs** replaces START_DIAGNOSTIC_TEST.bat, which is no longer included. It is off by default and remembered. The choice applies to the server, hidden worker and game of the next launch or LAN room, and it cannot change while a game or LAN room is running. Starting the launcher with `--diagnostics` still turns detailed logs on for that launcher session.
- **Collect a report if the game crashes** moved to this tab. **Collect full-memory crash dumps** is now a sub-option and is available only while crash reports are on. The first-start crash report question says where to change the choice later.
- **Create error report...** stays on the main screen, to the right of the game client status.

## Settlement

- A battle receipt that the client can never accept (for example, one whose edited values are outside the allowed range) is now reported once and acknowledged. Before, the server resent it on every connection and the same rejection was logged each time. A receipt that failed because the garage or save could not be written is still kept and retried.
