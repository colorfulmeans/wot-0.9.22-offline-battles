# wot-0.9.22-offline-battles v0.9.4

This release promotes the **original-policy Bot build `a3e4c593`** selected by the maintainer. It uses the upstream v0.7.7 Bot behavior with the already integrated radio-visibility and battle-start compatibility fixes. The separate **no-yield** experiment is **not** included.

Supported game client: Chinese HD **World of Tanks 0.9.22.0.1 #1513**.

## Bot behavior and maps

- Restore the upstream v0.7.7 navigation, driving, traffic coordination, tactical integration and Bot-owned runtime behavior, rather than extending the later avoidance/replanning layers.
- Retain the original author's short crossing yields and head-on coordination. This release does **not** remove all vehicle avoidance or physical collision.
- Use all 41 original navigation maps, formations and routes, including the original Airfield navigation graph. The experimental Airfield rebake is not included.
- Do not include the later broad native-static corridor review, live static-graph repair, second traffic braking layer or predicted rotation-veto additions.

## Retained integration fixes

- Preserve radio links and recipient-specific spotted contacts across the Bot observation producer, server relay and client presentation. Teammate position knowledge is no longer lost merely because the local player does not directly spot that teammate; draw distance and valid radio connectivity still apply.
- Preserve the startup fix for nonempty Bot rosters: the retained caller no longer passes an unsupported `required_tiers` keyword to the historical roster function.
- Retain current shared world/vehicle physics, garage, missions, economy, networking and other non-Bot systems from the selected build. This is **not** a downgrade of the entire game to upstream v0.7.7.

## Release packaging

- Update the launcher, Windows server, client mod, build identity and package metadata to **0.9.4**.
- Keep the runnable archive clean: launcher executable, `_internal`, README and license files only. Build evidence and test logs are stored separately in GitHub Actions artifacts.
- No additional gameplay changes are made on top of `a3e4c593` for this release.

## Installation

Close the previous launcher and both game processes. Extract the **whole** Windows ZIP into a **new empty folder**, run `wot-0.9.22-offline-battles.exe`, and select the existing #1513 game directory. Do not merge old and new `_internal` folders. No separate Python installation is required; do not reset saved data just to upgrade.

## Validation and remaining limits

The release build verifies source identity against the selected commit, original Bot and map hashes, targeted historical driving/radio/startup regressions, Python 2.7 bytecode, executable versions, package installation and bundled-server readiness. These checks do not establish new native-gameplay, jam-resolution or frame-rate results. Mutual yielding remains in this original-policy build, and remaining traffic jams require native testing.
